1. How to Run Locally

  • Node.js Requirement: Node.js (v18 or higher) installed on your system.
  • Port: Default port is 3000. To change port: PORT=4000 npm start.
  • Zero Bundler Setup: No Webpack or Vite build step required—pure vanilla JS/CSS for instant lightning-fast loading!
  • Hot Reload / Restart: Press Ctrl + C in terminal to stop, and npm start to restart.
📚

2. Studying Curriculum Modules

  • Every Concept includes 4 Essentials:
    1. 📌 Notes: In-depth theory and syntax explanation.
    2. 🌍 Real-World Example: Practical everyday analogy for intuition.
    3. 💻 Runnable Code Block: Complete code snippet with 1-click execution.
    4. 🎯 Concept Check MCQs: 2-3 instant interactive questions in the right column.
  • Interactive vs Readable Mode: Use the mode toggle pills above the modules to switch between side-by-side interactive mode and clean distraction-free reading mode.
  • Full-Resolution Diagrams: Click on any architectural image to open the fullscreen high-res lightbox view.
👨‍🏫

3. Dedicated Instructor Guide

  • Private Teaching Desk: Open the 👨‍🏫 Instructor Guide tab to access lecture breakdown strategies, blackboard analogies, and student gotchas.
  • Viva & Interview Bank: Detailed technical oral examination questions with model answers for all 30 topics.
  • Lab Rubrics: Clear grading criteria (30 Points Continuous Evaluation) for evaluating hands-on coding submissions.
💻

4. Operating Live Code Sandbox

  • 1-Click Code Loading: Click "⚡ Run in Sandbox" next to any code snippet across the modules to auto-load and execute it.
  • Presets Menu: Choose from preloaded templates (HTML5 card, DOM manipulation, Async Node.js simulation, React state counter, and Fetch API).
  • Live Execution: Click "⚡ Run Code" or press Ctrl + Enter to run in an isolated live preview iframe.
🔑

5. Operating JWT Security Lab

  • Generate Token: Enter a Developer ID and Name, then click "Generate Cryptographic Token".
  • Inspect Anatomy: View color-coded breakdown: Header (Algorithm), Payload (Claims), Signature.
  • Test Tampering: Click "Tamper Token Payload" to observe cryptographic signature failure (403 Forbidden).
  • Access Protected API: Call /api/auth/protected-profile using the generated Bearer token.
